# ניהול בחזית הסייבר

**מנהיגות, סיכון, אנשים וקבלת החלטות בעולם של בינה מלאכותית, אי ודאות ומשברים**

מאת: **יובל סיני**  
מהדורה: **1.0**  
שנת פרסום: **2026**

## על הספר

הספר "ניהול בחזית הסייבר" מיועד למנהלי סייבר, מנהלי אבטחת מידע, מנהלים טכנולוגיים ומקבלי החלטות הנדרשים להוביל אנשים, לנהל סיכון ולקבל החלטות בתנאי אי ודאות.

הספר מחבר בין מנהיגות וניהול לבין סייבר, בינה מלאכותית, חוסן ארגוני, קבלת החלטות, ניהול משברים, רגולציה, ספקים, שחיקה, ניהול ידע ופיתוח מנהלים. מטרתו אינה לספק רשימת בקרות נוספת, אלא להציע מסגרות חשיבה, דילמות, תרגילי החלטה וכלים מעשיים למנהלים.

## קבצי הספר

המאגר מיועד להפצת המהדורות הרשמיות של הספר בשלושה פורמטים:

- קובץ `PDF` לקריאה והפצה.
- קובץ `DOCX` לקריאה בתוכנות עיבוד תמלילים.
- קובץ `Markdown` לקריאה ישירה, חיפוש ושימוש נגיש דרך GitHub.

הגרסה הרשמית העדכנית תופיע בתיקיית `book/`. מהדורות קודמות יישמרו בתיקיית `archive/previous-editions/`.
