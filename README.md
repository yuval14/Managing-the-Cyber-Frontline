# ניהול בחזית הסייבר

**מנהיגות, סיכון, אנשים וקבלת החלטות בעולם של בינה מלאכותית, אי ודאות ומשברים**

מאת: **יובל סיני**  
מהדורה מתוכננת: **1.0**  
שנה: **2026**  
סטטוס: **הכנה לפרסום - קובצי הספר טרם פורסמו במאגר**

## על הספר

הספר "ניהול בחזית הסייבר" מיועד למנהלי סייבר, מנהלי אבטחת מידע, מנהלים טכנולוגיים ומקבלי החלטות הנדרשים להוביל אנשים, לנהל סיכון ולקבל החלטות בתנאי אי ודאות.

הספר מחבר בין מנהיגות וניהול לבין סייבר, בינה מלאכותית, חוסן ארגוני, קבלת החלטות, ניהול משברים, רגולציה, ספקים, שחיקה, ניהול ידע ופיתוח מנהלים. מטרתו אינה לספק רשימת בקרות נוספת, אלא להציע מסגרות חשיבה, דילמות, תרגילי החלטה וכלים מעשיים למנהלים.

## מצב הפרסום

המאגר נמצא בשלב הכנה למהדורה 1.0. בשלב זה מפורסמים בו רק קובצי תשתית ומטא-דאטה לצורך הכנת ההוצאה לאור.

קובצי הספר עצמם אינם זמינים עדיין במאגר. בפרט, טרם פורסמו גרסאות `PDF`, `DOCX` או `Markdown` של הספר.

כאשר המהדורה תאושר לפרסום, המאגר מיועד לשמש נקודת ההפצה הרשמית של הקבצים המאושרים.

## פורמטים מתוכננים

בעת הפרסום מתוכננים הפורמטים הבאים:

- קובץ `PDF` לקריאה ולהפצה.
- קובץ `DOCX` לקריאה בתוכנות עיבוד תמלילים.
- קובץ `Markdown` לקריאה ישירה, חיפוש ונגישות דרך GitHub.

תיקיית `book/` שמורה למהדורה הרשמית. אין לראות בקובצי המטא-דאטה שבמאגר תחליף למהדורה שפורסמה.
